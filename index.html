Changer les scores
  1. Les scores vivent dans scores.csv. Tapez-les ici pour voir le classement bouger tout de suite, puis Copier le CSV et collez dans le tableur : c'est ce qui compte pour tout le monde.
  2. Sur GitHub : ouvrez scores.csv, cliquez sur le crayon, changez les deux dernières colonnes, validez. La page suit dans la minute.
  3. Avec Google Sheets (le plus pratique à plusieurs) : importez scores.csv dans une feuille, puis Fichier → Partager → Publier sur le web → format CSV. Copiez le lien obtenu et collez-le dans index.html à la ligne const TABLEUR = "";. Chacun modifie la feuille, la page se met à jour toute seule.
